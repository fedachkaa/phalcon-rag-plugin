## [1.0.0] - 2026-10-25

### Added
- PhpStorm tool window for interacting with the Phalcon RAG Assistant.
- Integration with the Phalcon RAG backend via REST API.
- Support for attaching selected PHP code as context for questions.
- Markdown rendering for AI-generated answers.
- Clickable references to Phalcon documentation and Zephir source code.
- Source-code links with line-range navigation on GitHub.
- Configurable backend API URL in PhpStorm settings.
- Loading indicator and basic error handling for API requests.
- README with setup instructions, architecture overview, and video demo.
